# PeekSwitcher

Переключатель раскладки для Windows 11 (с заделом под macOS): сам исправляет слова,
набранные не в той раскладке, чинит опечатки и расставляет «ё». Живёт в трее.

**[Скачать последнюю версию](https://github.com/ilumetric/PeekSwitcher/releases/latest)** — архив
`PeekSwitcher-<версия>-windows-x64.zip`: распаковать в любую папку и запустить `PeekSwitcher.exe`.

## Возможности

* **Автопереключение раскладки** — `ghbdtn` → «привет», `руддщ` → «hello»; однобуквенные
  слова подтягиваются за следующим словом («d ljvt» → «в доме»).
* **Опечатки** — исправление с учётом соседних клавиш, три уровня (Min — середина — Max).
* **Ёфикатор** — «еще» → «ещё», только там, где «ё» однозначна.
* **Точка двойным пробелом**, как на macOS.
* **Заглавная в начале предложения** — после `.` `!` `?`, но не после «т.е.», «ул.», инициалов и многоточия.
* **Звуки** — своя мелодия для каждой раскладки, исправления и авторежима; файлы можно заменить.
* **Исключения** — программы (по умолчанию менеджеры паролей), где переключатель молчит,
  и слова, которые не трогаются.
* **Не мешает в играх** — молчит в полноэкранных окнах и в программах, захвативших мышь
  (игры, режим Play в Unreal Engine); в остальном редакторе, например при переименовании
  ассетов, работает как обычно. Отключается в настройках.
* **Выключатель в трее** — пункт «Включён» в меню значка полностью отключает переключатель.
* Работает в программах со своей обработкой клавиатуры (Blender и т.п.): слова
  перепечатываются настоящими нажатиями клавиш, а не Unicode-вводом.

## Клавиши

| Жест | Действие |
|---|---|
| Shift, Shift (дважды быстро) | исправить набираемое или последнее слово или выделение; сразу после автоисправления — отменить его и запомнить слово |
| Левый + правый Shift | включить / выключить авторежим |
| Shift (один раз, включается в настройках) | сменить раскладку |

## Сборка

Нужен [Rust](https://rustup.rs) (stable). Всё остальное подтягивает Cargo.

```
cargo run -p peekswitcher                       # отладочная сборка
cargo build --release -p peekswitcher           # рабочая: target/release/PeekSwitcher.exe
powershell -File tools/package.ps1             # релиз: папка dist/PeekSwitcher (exe + resources)
powershell -File tools/package.ps1 -Zip        # то же + dist/PeekSwitcher-<версия>-windows-x64.zip
```

Программе нужна папка `resources/` (словари и звуки). При запуске из `target/...` она
находится сама; для переноса положите `resources/` рядом с exe. Настройки хранятся в
`data/` рядом с exe, а если папка только для чтения — в `%APPDATA%\PeekSwitcher`.

## Выпуск версии

```
powershell -File tools/release.ps1 0.2.0
```

Скрипт поднимает версию в `Cargo.toml`, прогоняет тесты, коммитит, ставит тег `v0.2.0` и пушит.
Тег запускает [release.yml](.github/workflows/release.yml): GitHub Actions собирает zip и
публикует релиз с автоматическим списком изменений. Теги с суффиксом (`v0.2.0-beta.1`)
выходят как пре-релизы. Каждый пуш и PR проверяется [ci.yml](.github/workflows/ci.yml).

## Устройство

```
crates/pek-core      ядро без привязки к ОС: раскладки, словари, триграммная модель,
                     решение о переключении, опечатки, ёфикатор, конечный автомат набора
crates/pek-platform  интеграция с ОС (сейчас Windows): низкоуровневый хук клавиатуры,
                     SendInput, переключение раскладки, буфер обмена, звук, автозапуск
app/                 нативное окно (Slint, app/ui/app.slint), трей, сохранение настроек
resources/dict       словари (собираются tools/build_dicts.py из third_party/raw)
resources/sounds     звуки — можно заменить своими WAV 16 бит
tools/               генераторы словарей, иконок и черновых звуков
```

Пока идёт исправление, новые нажатия придерживаются и воспроизводятся следом в исходном
порядке, так что быстрый набор не перемешивается с исправлением.

## Проверки

```
cargo test -p pek-core                                   # логика ядра, симуляция набора
cargo run -p pek-core --example eval --release           # качество на незнакомых словах
cargo run -p pek-core --example probe --release -- слово # что модель думает о словах
cargo run -p pek-platform --example e2e                  # набор в реальном окне (при запущенном приложении)
```

Отладочный журнал: запустить с переменной `PEK_DEBUG=1`, лог пишется в `pek-debug.log` рядом с exe.
